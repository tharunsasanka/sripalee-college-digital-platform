# Project Start Checklist

## Local setup

- Install Node.js 20.9 or later
- Install Git
- Extract the starter package
- Configure the GitHub commit email
- Run `npm install`
- Run `npm run dev`

## GitHub setup

- Create the repository
- Push the initial commit
- Use feature branches
- Open pull requests
- Keep the report in the `docs` folder

## School approval work

- Obtain written approval from the Principal
- Confirm the school coordinator
- Confirm the official crest and colours
- Confirm approved public information
- Confirm photograph permissions
- Apply for the official `.sch.lk` domain through SchoolNet
- Confirm the final hosting and ownership arrangements

## Development order

1. Public homepage and navigation
2. Multilingual content structure
3. Teacher directory
4. News, announcements and events
5. Heritage archive
6. Digital noticeboard
7. Secure administration dashboard
8. Student and examination prototype using dummy data
9. Security review and official-data approval
