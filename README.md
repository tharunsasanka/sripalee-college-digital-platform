# Sripalee College Digital Platform

Development starter for a secure, multilingual and accessible government-school digital platform.

## Included

- Professional project proposal in `docs/`
- Next.js and TypeScript starter
- Maroon-and-gold design foundation
- Responsive navigation
- Smooth page transitions
- Subtle 3D-style interactions
- Public website route structure
- Static export configuration for free Cloudflare Pages hosting

## Important status

This is a development preview and is not yet the official website of Sripalee College.

Do not add real student records, examination results, guardian details or private staff information until written approval and an approved hosting arrangement are in place.

## Requirements

- Node.js 20.9 or later
- Git
- npm

## Run locally

```powershell
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build for Cloudflare Pages

```powershell
npm run build
```

Use `out` as the build output directory.
